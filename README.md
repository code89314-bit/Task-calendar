# 業務予定（入れ物）

ローテーションと休みから、その日の自分の担当とチェックリストを出すアプリです。

**このリポジトリには人の名前・休み・タスクなどのデータは入っていません。**
データは各自の端末（ブラウザ）の中にだけ保存され、QRコードで端末どうしで受け渡します。
QRで渡したデータはこのサイトのサーバーには送られません。

## 使い方
1. iPhone は Safari、Android は Chrome でこのページを開き、「ホーム画面に追加」します。
   （iPhone の Safari は 7日間開かないサイトのデータを消すことがあるため、必ずホーム画面から使ってください）
2. ホーム画面のアイコンから開き、「QRを読み取る」で職場の人のQRを読み取ります。
3. 「自分」で自分の名前を選びます。
4. 休みやタスクを直したら「QRで渡す」で周りの人に渡します。受け取った側は、こちらより新しい内容だけが取り込まれます。

## 公開の手順（GitHub Pages）
Settings → Pages → Branch を `main`、フォルダを `/ (root)` にして保存。
数分後に `https://<ユーザー名>.github.io/task-calendar/` で開けます。

## ファイル
- index.html … アプリ本体
- qrcode.js / jsQR.js … QRの作成・読み取り（LICENSES.txt 参照）
- sw.js / manifest.webmanifest / icon-*.png … ホーム画面追加とオフライン用
